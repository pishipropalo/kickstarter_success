# Прогнозирование Успешности Краудфандинговых Проектов Видеоигр на Kickstarter


**О проекте:**

Проект посвящен разработке и оценке моделей машинного обучения для прогнозирования успешности финансирования проектов видеоигр на краудфандинговой платформе Kickstarter. Дополнительно разработан интуитивно понятный пользовательский интерфейс, который позволяет разработчикам и инвесторам оценивать потенциальную успешность проектов еще до их запуска.

**Цель проекта:**

1. Разработать и оценить модель машинного обучения для прогнозирования успешности финансирования проектов видеоигр на краудфандинговой платформе.
2. Создать пользовательский интерфейс для практического применения разработанной модели.
   
## **Особенности и используемые технологии:**

Комплексный сбор данных: Парсинг детальной информации о проектах видеоигр с Kickstarter (2016-2025 гг.), включая текстовые описания и ссылки на медиаконтент, с использованием Selenium WebDriver для обхода динамической загрузки и защиты Cloudflare.

**1. Продвинутая предобработка данных и Feature Engineering:**

  - Очистка данных, обработка пропущенных значений и дубликатов.
  
  - Извлечение признаков из текста: Статистические (длина, количество абзацев, средняя длина предложения), лингвистические (язык, орфографические ошибки) и семантические (упоминания платформ, жанров, мультиплеера).
  
  - BERT-эмбеддинги: Использование модели SentenceTransformer ('all-mpnet-base-v2') для создания 768-мерных семантических векторов, сниженных до 150 измерений с помощью PCA, для захвата глубокого контекста текстовых описаний.
  
  - Признаки из временных данных: Длительность подготовки проекта, длительность кампании, календарные признаки (день недели, месяц, время запуска/дедлайна).
  
  - Признаки из изображений и видео: Анализ медиа по URL для извлечения визуальных характеристик (яркость, контрастность, резкость, насыщенность, энтропия, количество уникальных цветов) с использованием requests, Pillow и opencv-python.
  
**2. Сравнительный анализ моделей машинного обучения:**

  - Baseline Model (мажоритарный класс)
    
  - Регрессионные модели: Logistic Regression (L2, L1, Elastic Net), Ridge Classifier, SGDClassifier.
    
  - KNN: Различные метрики расстояний, масштабирование, отбор признаков (F-статистика, Mutual Information), снижение размерности (PCA).
    
  - SVM: SVC с RBF, полиномиальным, сигмоидным ядрами, LinearSVC.
    
  - Bagging-модели: Random Forest, Extra Trees.
    
  - Boosting-модели: AdaBoost, Gradient Boosting, XGBoost, LightGBM, CatBoost.
    
**3. Оптимизация и балансировка классов:** Двухэтапный подбор гиперпараметров (RandomizedSearchCV -> Optuna) и использование class_weight='balanced' или scale_pos_weight для борьбы с дисбалансом классов.

**4.Веб-приложение на Django:**

  - Разработано на Python с использованием фреймворка Django.
    
  - Интуитивно понятный интерфейс для ввода параметров проекта.
    
  - Интеграция лучшей модели (LightGBM) для прогнозирования успешности.
    
  - Сохранение истории введенных данных в базе данных SQLite.
    
  - Обработка и извлечение признаков из пользовательского ввода в реальном времени, включая анализ текста (BERT), временных данных и мультимедиа.
    
## **Результаты**
В ходе исследования была достигнута значительная точность прогнозирования успешности проектов, значительно превосходящая бейзлайн-модель.

### **Ключевые метрики лучшей модели (LightGBM):**

| Модель   | Accuracy | F1 (weighted) | AUC-ROC | AUC-PR | MCC    |
| :------- | :------- | :------------ | :------ | :------ | :------ |
| **LightGBM** | **0.8612** | **0.8608** | **0.9308** | **0.8909** | **0.6871** |


**Основные выводы:**

Анализ важности признаков подтвердил, что успешность краудфандинговых проектов в сфере видеоигр определяется не только количественными и статистическими показателями. Существенное влияние оказывают предикторы, полученные из текстового описания (BERT-эмбеддинги, орфографические ошибки) и медиаконтента (количество уникальных цветов, наличие анимированных изображений). Это подчёркивает необходимость комплексного подхода, включающего глубокий анализ как содержательной, так и визуальной составляющей проекта.

## Установка и запуск

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/your-username/your-repo-name.git
    cd your-repo-name
    ```
2.  **Создайте и активируйте виртуальное окружение:**
    ```bash
    python -m venv venv
    source venv/bin/activate  # On Windows: `venv\Scripts\activate`
    ```
3.  **Установите зависимости:**
    ```bash
    pip install -r requirements.txt
    ```
    _Примечание: Для `Selenium` может потребоваться установка соответствующего веб-драйвера (например, `chromedriver`) и его настройка._
4.  **Запуск веб-приложения (Django):**
    ```bash
    cd src/web_app/Django_for_AI
    python manage.py makemigrations
    python manage.py migrate
    python manage.py runserver
    ```
    После запуска приложение будет доступно по адресу `http://127.0.0.1:8000/`.

5. **Доступ к панели администратора (опционально):**
   Вы также можете войти в панель администратора по ссылке: http://127.0.0.1:8000/admin

   В панели администратора вы сможете просматривать историю проектов, введенных пользователями.
